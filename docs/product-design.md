# ExileKit 产品规则 — Milestone 3

ExileKit 是 POE / POE2 的轻量工具入口。网站、第三方程序和用户快捷方式统一呈现为 Tool：突出图标和名称，点击后使用。无需向用户解释 Manifest、Provider、URL / EXE / LNK 类型或安装元数据。

## 导航与工具库

一级导航只有 Home、POE、POE2、Settings。POE / POE2 沿用 Manifest 的 `games` 筛选及现有搜索，不建立 GameContext、ToolFamily、自动游戏路由或按网站 / 程序划分的区域。Custom Shortcut 默认只属于 Home，不进入官方游戏工具库。

Favorites 和 Recently Used 的既有配置与统计继续保留，但不占据一级导航；Home 不直接等同于 Favorites。用户可见品牌使用 ExileKit，现有 `POEToolbox.exe`、命名空间与仓库目录可以保留，避免无关重命名。

## 图标网格（2026-09 UI 调整）

Home / POE / POE2 复用 ToolIconItem 与 ToolIconGrid。默认只显示 72 DIP 图标及居中的名称，名称最多占两行并截断；没有卡片背景、描述或常驻操作按钮。悬浮时通过轻量原生 Tooltip 展示完整名称、描述及必要状态，右键提供当前工具适用的管理操作，左键沿用既有启动 / 定位逻辑。

顶部只保留搜索。Home 的“添加快捷方式 / Add Shortcut”始终作为普通网格项目排在工具后面，空 Home 配合欢迎语显示，搜索无结果时仍可添加；POE / POE2 不显示添加项。Home 支持 Ctrl+N 打开相同弹窗，图标继续使用已有缓存与异步获取机制，不增加持续动画计时器。

## Home 是用户自己的快捷桌面

没有可见 Home Tool 时显示简短欢迎语和添加入口，不预填推荐工具，不重复提供 POE / POE2 跳转按钮。有工具后自然显示快捷方式网格。Home 没有固定数量上限，不加入新闻、行情、广告或复杂推荐。

Home 来源统一使用同一状态：近期重复使用自动加入、工具库中的 Add to Home、用户添加的 Custom Shortcut。时间规则由 `HomeService` 集中处理，输入 Unix 秒时间戳；UI 不自行计算过期，也不创建定时清理轮询。

| 行为 | 规则 |
|---|---|
| 成功打开 | 仅成功打开网站或启动程序后，累计一次使用次数并记录时间；失败不计入 |
| 自动加入 | 两次成功使用的间隔小于当前移除周期；Never 策略使用 30 天作为自动加入的近期判断窗口 |
| Add to Home | 作为普通项目加入，清除用户隐藏标记；不自动 Pin |
| Pin to Home | 用户明确选择后固定，始终保留，不参与过期 |
| Unpin | 恢复普通规则；已有时间记录很旧时可以立即过期 |
| Remove from Home | 隐藏并取消固定，保留工具定义、使用记录、用户路径和磁盘文件 |
| 手动恢复 | Add to Home 或 Pin to Home 清除隐藏标记；后续普通启动不会自行取消用户隐藏 |

普通项目默认 30 天未使用后移出 Home，Settings 可选 7 天、30 天、90 天、从不。过期判断以最近成功使用时间和手动加入时间中较新的时间为准，达到周期边界即过期。Custom Shortcut 遵循相同规则。

已过期项目保留数据，但不能仅凭很久以前的累计次数，在一次新启动后马上自动回来；重新达到近期重复使用条件后才自动加入。旧版 M2.5 配置没有 Home 状态时，可以从仍在近期窗口内、累计成功使用至少两次的记录初始化 Home。

固定项目优先，按固定时确定的顺序稳定显示；使用次数变化不移动固定项目。普通项目先按最近使用，再按累计次数排序，最后使用加入时间和稳定 ID 消除排序歧义。第一版不提供拖动排序。

## 添加自己的快捷方式

Home 的 `+` 打开一个输入框、Browse、取消、添加。用户输入网址或程序路径，或明确浏览选择 `.exe` / `.lnk`。系统识别类型并获取名称，不要求填写类别、游戏、名称、图标或 Provider，也不扫描桌面、开始菜单、注册表或磁盘。

- URL 优先使用网页标题 / 站点信息，失败时保留域名作为名称；网页信息和 favicon 在后台获取，添加不等待网络。
- EXE 优先使用 ProductName、FileDescription，再回退文件名。
- LNK 使用快捷方式名称，解析目标及指定图标；启动保留快捷方式原有目标、参数和工作目录语义。
- 无效输入使用简单本地化错误提示；底层保留结构化错误。

用户快捷方式由现有 ConfigManager 保存到用户数据，不能写入 `tools/manifests/`。schema 1 增加可选 `home`、`homeAutoRemoveDays`、`customTools` 字段，旧配置仍可读取；有效状态原子保存，无效状态不能覆盖已保存文件。输入大小限制是配置安全边界，不是 Home 项目数量配额。

## 图标与执行边界

统一 IconProvider 负责 bundled 图标、程序资源、快捷方式图标、网站缓存和后台 favicon；UI 只接收可用图像并使用占位图回退。先显示页面，再按需补齐图标。缺图和网络失败不能阻止工具显示、Home、启动或本地操作，已有缓存无需每次联网重取。

普通用户点击 Tool 后由底层选择网站、程序或快捷方式启动方式。风险确认按工具风险元数据统一处理。右键菜单中的 Add / Pin / Unpin / Remove 表达 Home 行为，不伪装成安装或卸载。

外部程序保留用户原始安装位置。真正 Managed App 的下载、更新和卸载由后续 Package Manager 实现；本阶段不提供会删除用户文件的假 Uninstall，不改变 Defender、防火墙、UAC 或第三方更新策略。
