# ExileKit Milestone 3 — 验证记录

## 交付内容

Home / POE / POE2 / Settings 四项导航，个人 Home、固定与移除、7 / 30 / 90 天 / Never 策略、URL / EXE / LNK 添加弹窗、自动名称和图标、网站元数据与 favicon 后台获取已经接入。公共清单及游戏筛选保留；自定义数据单独保存在用户配置，默认数据目录为 `%LOCALAPPDATA%\ExileKit`。

配置兼容 schema 1，旧配置仅复制、已有程序不移动。损坏配置先保留恢复副本；超长名称按 UTF-8 边界处理，新增快捷方式及网页名称更新在提交前验证可保存性。没有包管理、自动更新、游戏进程操作或系统安全设置变更。

## 验证方法与边界

- Core / Platform：假时钟覆盖自动加入、周期边界、Pin / Unpin、手动隐藏、100 项 Home 和旧配置；EXE / LNK 使用本项目 fixture 验证真实启动、中文路径、参数、工作目录和图标回退。
- Application：覆盖空 Home、启动零网络、自定义快捷方式添加、异步名称、缓存去重、成功 / 失败计数、移除后不自动恢复、损坏配置恢复、容量超限拒绝后继续保存。
- 网络隔离：可取消的阻塞 HTTP 替身保持请求未完成，期间执行设置、Home 操作及真实 EXE 启动，随后验证退出取消活动请求、丢弃排队请求并保存状态。
- 网页元数据：离线替身覆盖 HTML / entity / UTF-8 标题、相对图标、HTTPS 重定向、大小限制、有效缓存零请求、失败缓存 24 小时及取消。
- 绘制：实际 D2D / DWrite / WIC Renderer 生成双语、五档 DPI、两种宽度、四个页面及空 Home。已检查中文 Home、欢迎页、英文窄窗口 200% Settings；输出不含 native EDIT、按钮、标题栏及系统滚动条。
- 原生窗口：开发脚本验证四导航、即时双语标题、搜索、滚动、原生添加弹窗、EXE 整卡启动、最小化 / 最大化 / resize / 合成 DPI 和正常退出。显式网站卡片启动已到达默认浏览器调用，浏览器最终页面未检查。

冷启动、真实 4K / 多显示器物理跨屏、Windows 11、设备丢失恢复与文件选择器实际选中 EXE / LNK 的交互尚未验证。文件选择器代码与路径解析测试不能代替这些实机验证。

最终构建、真实网络与性能结果见本文后续记录及 [performance.md](performance.md)。历史 M2.5 验收记录保留在 [acceptance.md](acceptance.md)。

## 2026-09-12 最终结果

Debug / Release 构建均通过，CTest 各 11/11。最终新增的 LNK 自有图标优先、缺图回退测试也已在两种配置通过；Release 后续单独补跑该项仍通过。分发目录为 `out/package/ExileKit-0.3.0`，内部 exe 为 `POEToolbox.exe`，版本资源为 ExileKit 0.3.0，嵌入 manifest 保持 asInvoker / PerMonitorV2，仅依赖 Windows 系统 DLL。

真实 WinHTTP 测试使用 127.0.0.1 临时端口，仅接受 TLS 握手并故意不响应：250 ms 截止请求及时超时，活动请求取消样本约 33–52 ms，六条连接全部释放。沙盒内 Schannel 返回 12185，故最终传输测试及完整 CTest 在常规 Windows 进程中执行，未改动 TLS、证书或系统安全设置。公开站点 `https://poe.ninja/` 的实际标题与 favicon 解码成功。

分发程序的原生添加弹窗、LNK 整卡启动、网站打开和退出已验证；独立配置下的 EXE 弹窗路径也通过。性能测试没有并发构建，20 次热启动仍受运行环境影响：M3 沙盒中位数 80.09 ms，常规进程一组 168.25 ms；旧版相同脚本两组为 78.48 ms / 187.70 ms，不能将跨组差异直接判定为软件回退。完整数据与内存边界见性能记录。

## 2026-09-12 应用图标

项目所有者提供的原图已保留在 `assets/branding`，生成 16 / 24 / 32 / 48 / 64 / 128 / 256 像素 ICO，嵌入应用资源并用于窗口标题栏和任务栏。窗口在 DPI 变化时重新加载对应尺寸，替换与销毁时释放其拥有的图标句柄。

Debug / Release 构建通过，Release CTest 11/11 通过。最终分发程序通过 `scripts/smoke.ps1 -VerifyApplicationIcon -WarmSamples 0` 检查：初始 96 DPI、合成 120 / 144 / 168 / 192 DPI 和恢复后的大小图标尺寸均符合系统指标，正常退出；这不替代物理跨显示器测试。ICO 七帧目录和 EXE 提取图标也已检查。Release EXE 为 1,000,448 bytes，较图标接入前增加 218,112 bytes；原图不进入运行时分发目录。此前性能记录为图标接入前的数据。
