# Local icons

`generic-web.png` is an original, generic globe drawn for POE Toolbox; it is not a third-party product logo. No third-party binary or favicon is redistributed.
Manifests may refer to `resources/icons/generic-web.png`, or a reviewed locally bundled asset. Missing/bad assets fall back to cache or a colored initial placeholder. EXE resources are read only after the user configures a path. Website favicons are fetched asynchronously after user interaction and cached in user data; startup does not request them.

The application icon comes from the owner-supplied artwork in `assets/branding`; its generated ICO is embedded in the executable separately from tool icons.
